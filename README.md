# 🇬🇧 PatchTools

_Small tools for a more relaxed adventure in Classic Era and Forever._

## Features

- Automatically sell junk and repair your equipment
- Choose which items to sell and which to protect
- Zoom the camera out further
- Keep the world in color while you are a ghost
- Show cooldown numbers, item IDs and vendor prices
- Keep auto-loot enabled and collect loot faster
- Make item deletion more convenient
- Get warnings before announced world refreshes on Forever

Choose the features you want. English and German are included.

**Try the alpha:** optional quest automation with Pawn support, more appearance options and a matching settings window. Pair it with the [PatchToolsMaps alpha](https://www.curseforge.com/wow/addons/patchtoolsmaps) for the modern map experience. The alpha is a public test version and is likely to contain bugs. The stable version remains available.

**More room for your adventures:** add [PatchToolsMaps](https://www.curseforge.com/wow/addons/patchtoolsmaps) for the world map and [PatchToolsBags](https://www.curseforge.com/wow/addons/patchtoolsbags) for your bags.

## Commands

| Command | What it does |
| --- | --- |
| `/patchtools debug` | Open a copyable diagnostic report with addon versions and load states. |
| `/patchtools` | Open the settings. |
| `/patchtools status` | Show information useful for a bug report. |
| `/patchtools reset` | Reset the settings window position and size (alpha). |

You can also use `/ptools` instead of `/patchtools`.

# 🇩🇪 PatchTools

_Kleine Helfer für entspanntere Abenteuer in Classic Era und Forever._

## Funktionen

- Schrott automatisch verkaufen und die Ausrüstung reparieren
- Selbst bestimmen, welche Items verkauft und welche geschützt werden
- Die Kamera weiter herauszoomen
- Die Welt auch als Geist in Farbe sehen
- Abklingzeiten, Item-IDs und Händlerpreise anzeigen
- Automatisches Plündern beibehalten und Beute schneller einsammeln
- Das Löschen von Items bequemer machen
- Auf Forever vor angekündigten Welterneuerungen gewarnt werden

Aktiviere die Funktionen, die du möchtest. Deutsch und Englisch sind enthalten.

**Probiere die Alpha:** optionale Questautomatik mit Pawn-Unterstützung, mehr Gestaltungsmöglichkeiten und ein dazu passendes Einstellungsfenster. Zusammen mit der [Alpha von PatchToolsMaps](https://www.curseforge.com/wow/addons/patchtoolsmaps) bekommst du auch die moderne Kartenansicht. Die Alpha ist eine öffentliche Testversion und enthält sehr wahrscheinlich noch Fehler. Die stabile Version bleibt verfügbar.

**Mehr Platz für deine Abenteuer:** ergänze [PatchToolsMaps](https://www.curseforge.com/wow/addons/patchtoolsmaps) für die Weltkarte und [PatchToolsBags](https://www.curseforge.com/wow/addons/patchtoolsbags) für deine Taschen.

## Befehle

| Befehl | Funktion |
| --- | --- |
| `/patchtools debug` | Kopierbaren Diagnosebericht mit Addon-Versionen und Ladestatus öffnen. |
| `/patchtools` | Die Einstellungen öffnen. |
| `/patchtools status` | Hilfreiche Informationen für einen Fehlerbericht anzeigen. |
| `/patchtools reset` | Position und Größe des Einstellungsfensters zurücksetzen (Alpha). |

Statt `/patchtools` funktioniert auch `/ptools`.
